# StudyMate AI — Next.js Frontend

## Setup

```bash
npx create-next-app@latest studymate-frontend --typescript --tailwind --app --no-src-dir
cd studymate-frontend
```

Then replace the following files with the ones provided:
- `app/page.tsx` → main UI
- `app/globals.css` → global styles
- `app/layout.tsx` → layout with fonts

## Run
```bash
npm run dev
```

Make sure your Python backend is running on http://localhost:8000
